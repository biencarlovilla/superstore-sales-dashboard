# Power BI Dashboard Development Recordings

This folder documents the development process for the Superstore Sales Performance Dashboard.

## Development Stages

1. **Data Import:** Imported the Superstore CSV dataset into Power BI.
2. **Data Cleaning:** Reviewed data types, corrected formatting, and checked for duplicates.
3. **Data Modeling:** Prepared the dataset for reporting.
4. **DAX Calculations:** Created five measures for the dashboard KPIs.
5. **Dashboard Creation:** Built KPI cards and analytical charts.
6. **Dashboard Polishing:** Applied consistent formatting and a dark theme.
7. **Interactive Slicers:** Added Year, Region, and Category filters.
8. **Final Demonstration:** Tested the interactive dashboard and demonstrated its features.

## Final Dashboard Showcase

The final recording demonstrates how users can filter sales performance by year, region, and product category.

Development recordings are retained separately and may be added after reviewing them for private information.
